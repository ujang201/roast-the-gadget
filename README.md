## The entry

One original line roasting the wireless earbuds I use every day:

> My earbuds die at 3% while their case sits at 100% — the case is just a tiny coffin with a charging port.

The joke is the betrayal: the case exists for exactly one job — keeping the earbuds alive — and it does that job perfectly for itself while letting the earbuds die. A coffin with a charging port is the image that makes the gripe stick.

The line is 105 characters, comfortably inside the bounty gate of 1–200 characters, and it names a specific daily gadget with a concrete, lived-in detail rather than a generic complaint.

## How it works

`main.ts` (Node 22, no dependencies) writes that single line to `$OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The output is fully deterministic: same bytes on every run.

## Run it

```sh
node main.ts
# or, with an explicit output directory:
OUTPUT_DIR=/tmp/out node main.ts
```
